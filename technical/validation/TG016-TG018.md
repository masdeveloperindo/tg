## TG-016

Admin terverifikasi dan reauthentication baru membuka `/admin/pesanan`. Modal konfirmasi mewajibkan cek dana, referensi dan catatan pemeriksaan mutasi. Penolakan memerlukan alasan. Nilai order bukan input browser; status waiting dan deadline diperiksa server. Konfirmasi order expired ditolak agar pembayaran terlambat ditangani manual. Telegram tidak memicu mutasi.

Transaksi mengunci order lalu lisensi; status paid, waktu/admin pemeriksa, penerbitan atau renewal, dan audit berhasil bersama. Kegagalan audit membatalkan semuanya. Retry paid mengembalikan receipt lama; dua worker PHP independen mengonfirmasi order yang sama dan terbukti tidak menduplikasi lisensi/audit. Browser membuang respons setelah commit dan Cek Status GET tetap menemukan satu order lunas. Client, admin belum TOTP dan reauthentication kedaluwarsa ditolak.

## TG-017

Key memakai random_bytes(16):128bit,8 grup hex uppercase masing-masing4karakter. Format ini memperkuat contoh key4grup pada PRD/API; kontrak API diberi catatan agar verifier berikutnya tidak memotong key. Penyimpanan cast encrypted dan SHA-256 lookup, unique key hash serta triple pemilik/produk/akun. Tidak ada key mentah di URL, admin DOM atau audit. Renewal menjaga ciphertext/hash dan issued_order_id awal, hanya memperpanjang tahun/expiry; replay tidak memperpanjang dua kali.

`/admin/lisensi` memungkinkan active→suspended, suspended→active selama belum expired, serta active/suspended→revoked permanen. Alasan kategori wajib; intent UUID di-hash dengan identitas actor dan disimpan dalam audit. Retry payload sama mengembalikan state terkini, tidak mengulang suspend lama setelah reaktivasi; payload berbeda dengan intent sama ditolak. Cache state dibuang setelah commit. Audit hanya metadata bertipe yang diizinkan, tidak mencatat key/catatan bank bebas.

## TG-018

Pemilik invoice lunas mendapat tautan unduh minimal; portal key dan riwayat lengkap tetap TG-021. Permintaan memeriksa lisensi aktif dan belum expired, membuat URL signed maksimal5menit atau sisa expiry yang lebih pendek. URL mengikat id lisensi/versi/fingerprint HMAC status, identitas, expiry dan timestamp perubahan. GET memeriksa ulang sesi owner, policy, signature, fingerprint dan versi aktif/released milik produk yang sama. Uji owner lain, manipulasi versi/state, URL expired, suspend/revoke/expiry serta korupsi file ditolak.

Canonical storage root wajib di luar public. Path versi berpola UUID privat; handle shared-lock yang dibaca untuk ukuran/SHA-256 sama dengan handle stream. File tidak dieksekusi. Respons attachment octet-stream, private/no-store/nosniff. Byte yang sudah dikirim tidak dapat ditarik kembali; ini bukan bukti revoke EA offline atau kelulusan gate terminal.
