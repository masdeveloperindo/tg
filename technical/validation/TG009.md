# TG-009 — Modal dan feedback bersama

**5 November 2026 — DONE.** Perubahan lokal, belum dipush/PR. Komponen `ui/modal`, `loading`, `errors`, `toast`, `upload-status` dan `request-feedback` tersedia. Reset password admin memakai modal bersama; policy, verifikasi identitas, reauth dan pencabutan sesi tetap diperiksa server.

Dialog native memakai label/deskripsi, fokus awal, focus trap Tab/Shift+Tab, latar inert dan pemulihan fokus. Escape diblokir saat reset berjalan atau hasil request belum pasti. Toast dapat ditutup tanpa timer buatan. Loading mengikuti request Livewire. Persentase upload hanya berasal dari event transfer; selesai transfer belum berarti validasi/penyimpanan berhasil.

Interceptor Livewire menangani kegagalan jaringan, HTTP error dan respons yang belum datang setelah 30 detik. Pesan tidak merender payload/stack trace server. Sesi401/419 menampilkan pesan sesi habis tanpa browser confirm. Status belum pasti memblokir pengulangan aksi; Cek Status melakukan navigasi GET ke halaman yang sama, tanpa retry mutasi. Respons terlambat tetap dapat menyelesaikan navigasi sah dari server. Hasil reset yang hilang memerlukan pemeriksaan akun dan verifikasi manual sebelum reset baru.
