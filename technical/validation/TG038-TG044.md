## Perubahan QA

Worker kini memakai transaksi outer dengan retry terbatas 3 kali dan mengulangi snapshot/operasi penuh. Parent memeriksa batas attempts dan connection ID berbeda; invariant uang/idempotency tetap diuji. Full run sesudah perubahan PASS. Ini perbaikan harness pengujian; action keuangan produksi tetap menggunakan row lock, decimal dan transaction retry yang sudah tersedia.
