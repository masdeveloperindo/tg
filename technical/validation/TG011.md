## Cakupan

- `/admin/produk`, `/admin/produk/create`, `/admin/produk/{id}/edit`: daftar berpaginasi dan satu editor tujuh tab untuk informasi, preview/cara pakai, performa, file/versi, FAQ, harga dan SEO.
- Policy admin aktif+TOTP, otorisasi ulang pada setiap action/service, ID produk locked pada snapshot, query child scoped ke produk, endpoint file/temporary upload/preview privat. Sesi expired/role salah tidak dapat mengubah produk.
- Harga DECIMAL/string, minimum tidak melebihi harga awal, slug unik. Draft/published/archived memakai modal; arsip mempertahankan data historis. Tidak ada tombol penjualan dan setiap mutasi produk mempertahankan sale_enabled=false. Harga dasar belum merupakan kuotasi kalender TG-013.
- Deskripsi/FAQ/petunjuk HTML memakai allowlist DOM: hanya struktur teks dan link HTTPS; script, namespace aktif, embed, style dan atribut event dibuang. Slug produk published dikunci agar URL yang pernah dipublikasikan stabil; redirect slug/SEO penuh mengikuti task berikutnya.
- Screenshot JPG/PNG/WebP maksimal2MiB, maksimal8MP/sisi6000px, re-encode menjadi WebP dengan sisi maksimal1600px dan metadata dibuang. Nama acak, storage privat; alt text wajib. Video hanya link HTTPS YouTube/Vimeo tanpa credential/port, tidak di-fetch atau di-embed server.
- Tutorial berurutan dan gambar yang sudah dimiliki produk; FAQ dan metadata media dapat diedit. Hasil backtest/forward test mencatat demo/real, periode, simbol/timeframe, kondisi, metode, angka opsional dan editor/waktu. Kosong disimpan NULL, tidak diisi angka/kurva simulasi. Laporan PDF privat maksimal5MiB dan gambar equity opsional.
- Versi EX5 privat maksimal20MiB dengan checksum/ukuran server. Hanya header EX5-NUL atau 0x7fEX5 diterima pada format gate saat ini. Nama versi unik; pengaktifan mengunci produk dan mengganti versi aktif dalam satu transaksi, didukung constraint DB. Metadata versi dapat diedit, file historis tetap disimpan. File tidak pernah dieksekusi server.
- Audit produk/transisi/versi/media/FAQ/tutorial/performa; perubahan performa memiliki editor, resource ID dan hash sebelum/sesudah. Audit tidak menyalin isi bebas/path/rahasia. Bukti sumber tetap privat saat presentasi dihapus. File baru dibersihkan jika transaksi gagal.

## Reproduksi browser

Ikuti prosedur e2e terisolasi di DEVELOPMENT.md: seed `tests/Browser/seed.php` hanya pada APP_ENV=e2e/MySQL8.4 tg_test; jalankan server port8081 dengan --no-reload. Buat gambar sintetis dan jalankan runner:

```bash
docker compose run --rm --no-deps app php -r '$im=imagecreatetruecolor(32,20); imagepng($im);' > /workspace/.tg-cache/tg011-image.png
node tests/Browser/products.cjs
```

Runner membuat produk sintetis melalui UI, menyimpan FAQ/tutorial, benar-benar mengunggah gambar dan file versi sintetis, menambah metadata performa, mengaktifkan versi, membatalkan/menyetujui modal publikasi, lalu memeriksa tujuh tab pada360/768/1280 dan keyboard. Tidak mengambil screenshot OTP/password. Jangan menjalankan suite PHP bersamaan karena database test yang sama digunakan.
