## Cakupan yang dibuktikan

- `/produk`: katalog published-only, pencarian/filter tipe dan pagination. Beranda juga membaca produk published; draft/archived tidak muncul. Empty state tetap jujur.
- `/produk/{slug}`: satu halaman berisi deskripsi, preview, cara pakai, backtest/forward test beserta label real/demo dan metode, changelog versi yang sudah dirilis, FAQ aktif dan ulasan yang memiliki consent/publikasi. Bagian tanpa data disembunyikan; angka NULL tidak diganti nol atau kurva simulasi.
- Harga dasar belum ditampilkan sebagai kuotasi kalender. Penjualan tetap tertutup, tanpa checkout atau schema Offer palsu. Pricing/order mengikuti TG-013 dan seterusnya.
- Gambar preview/equity/panduan hanya dilayani untuk produk published; unpublish menutup akses berikutnya. File EA, PDF bukti dan consent/path privat tidak masuk HTML/snapshot publik. Video hanya link HTTPS YouTube/Vimeo, tanpa embed atau fetch server.
- `/broker`: hanya broker aktif dengan tarif sudah efektif. Link HTTPS hanya tampil bila hostname persis ada di allowlist owner/legal, tanpa credential/port/IP/internal address. Default allowlist kosong; tidak membuat mitra atau URL contoh produksi.
- Kalkulator berlabel estimasi memakai BCMath/string dan rate DB, output4desimal; tidak mengubah wallet/ledger. Angka yang ditampilkan bukan saldo/janji hasil. Input dibatasi dan action dibatasi30perIP/menit; hasil tidak dapat ditimpa lewat properti client.
- Metadata title/description, canonical berbasis APP_URL, Open Graph/Twitter dan JSON-LD Product aman dari penutupan script. Gambar sosial memakai preview yang tersedia. Sanitasi HTML tetap diterapkan saat baca untuk konten impor. Disclaimer risiko tampil pada halaman publik.

## Reproduksi dan batas

`tests/Browser/seed-catalog.php` memanggil guard seed e2e yang memeriksa APP_ENV=e2e dan database aktual MySQL8.4 tg_test sebelum migrate:fresh. Fixture produk/broker/ulasan seluruhnya sintetis. Gunakan TG_PRIVATE_STORAGE_PATH=/app/storage/framework/testing/e2e-private pada seed dan server, serta TG_BROKER_REFERRAL_HOSTS=partner.example.invalid hanya untuk server fixture. Server port8081 wajib memakai --no-reload. Runner: `node tests/Browser/catalog.cjs`. Jangan menjalankan suite PHP bersamaan dengan browser karena memakai database test yang sama.

Browser menguji pencarian, detail lengkap dan kosong, gambar yang benar-benar termuat, estimasi server, satu h1/main, canonical, overflow dan screenshot di tiga viewport. Tidak melakukan pembayaran atau membuka URL mitra.

SEO penuh/sitemap, redirect slug, Core Web Vitals dan seluruh G-27 mengikuti TG-036/QA berikutnya. Admin broker tetap TG-023; halaman legal/edukasi/panduan mandiri mengikuti task konten masing-masing. Owner/legal/source EA dan PoC terminal tetap belum tersedia. **SOFTWARE READY FOR HANDOFF: NO; GO-LIVE: NO.**
