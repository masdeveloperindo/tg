Pengaturan Telegram pribadi (demo)

Username tidak ditentukan di HTML. Admin memasukkan akunnya sendiri saat implementasi; tanpa bot/webhook.

Contoh ilustratif: akun Anda sendiri. Jangan mengisi token atau chat ID bot.
Ketika terisi, tombol Chat Admin hanya membuka t.me/username. Tidak ada pesan terkirim otomatis.
